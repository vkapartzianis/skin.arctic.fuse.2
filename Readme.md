# Project status

The upstream Arctic Fuse 2 skin is deprecated. Upstream development continues in Arctic Fuse 3:

https://github.com/jurialmunkey/skin.arctic.fuse.3

This fork maintains Arctic Fuse 2 for inclusion with Kine, a Quest-focused fork of Kodi.

Some updates in this fork, such as symbolic icon support and touch-friendly home widgets, depend on support from the Kine side. For testing outside Quest-specific builds, an Android APK is available in the Releases section.
